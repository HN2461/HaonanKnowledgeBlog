## 先给总路线

Codex 现在不要按“先背配置、再学功能”的方式读。  
更适合程序员的路线是：

1. 先把 CLI 第一日用顺
2. 再看懂英文终端、菜单、权限、插件和错误提示
3. 然后建立配置层级和安全边界
4. 再把 CLI、VS Code 插件、桌面 App 串成日常开发流
5. 最后按场景查字段、查界面、查线路和排障

如果主人今天只想把 Codex 用得更顺，优先读前 4 篇就够。
