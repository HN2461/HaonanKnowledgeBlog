# MCP 个人实践与踩坑记录

这个目录专门记录“真实项目发生过的问题”，不写泛泛教程。

建议每篇记录都按下面结构：

1. 场景背景
2. 问题现象
3. 复现步骤
4. 根因分析
5. 修复方案
6. 预防策略
7. 可迁移经验

首批可以优先记录这几类：

1. 浏览器连接失败或超时
2. 无法稳定定位元素
3. 跨域或登录态导致流程中断
4. 权限过高引发的安全隐患
