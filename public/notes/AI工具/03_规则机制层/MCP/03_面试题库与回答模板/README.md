# MCP 面试题库与回答模板

本目录用于沉淀 MCP 面试高频问法与标准回答模板。

复核日期：2026-05-24

当前按 3 组拆分，方便你按场景刷题：

1. [第一组：概念与主流度问题](第一组_概念与主流度问题.md)
2. [第二组：架构与安全边界问题](第二组_架构与安全边界问题.md)
3. [第三组：项目落地与收益评估问题](第三组_项目落地与收益评估问题.md)

建议使用方式：

1. 先背每题的 `30 秒回答`，保证第一轮能稳住
2. 再熟悉 `2 分钟展开`，保证追问时能接住
3. 最后补 `追问应对` 和 `可反问面试官的问题`，把回答从“会背”变成“像做过”

每道题统一结构：

1. 问题原文
2. 30 秒回答
3. 2 分钟展开
4. 追问应对
5. 可反问面试官的问题

维护规则：

1. 结论优先对齐官方概念，再结合你的实战经验落地
2. 高时效信息尽量标注复核日期，避免旧口径长期悬挂
3. 回答里优先使用“能力分类 + 权限治理 + 落地收益”这条主线
4. 如果你后续有真实项目案例，优先补进第三组，面试价值最高
