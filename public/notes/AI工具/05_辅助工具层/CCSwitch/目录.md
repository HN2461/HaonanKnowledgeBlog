## 覆盖主题

- 工具定位：跨平台桌面 All-in-One AI CLI 配置管理中控台
- 支持工具：Claude Code、Codex CLI、Gemini CLI、OpenCode、OpenClaw、Hermes Agent（v3.14.0+），以及 Claude Desktop 独立管理面板（v3.15.0+）
- 工具管理：受管 CLI 工具安装、升级、版本检查、批量动作与冲突诊断（v3.16.0 重点增强）
- 工具诊断：按来源感知 PATH、Homebrew、npm、pnpm、bun、WinGet、Scoop、WSL 等安装来源，并生成更贴近真实来源的升级命令
- Provider 管理：新增、切换、速度测试（Stream Check）、故障转移、一键回滚、Routing Support 标识
- 本地路由（Local Routing）：热切换、自动故障转移、熔断器、请求日志（v3.9.0+）
- 兼容能力：OpenAI 兼容 `/v1/models`、部分 Anthropic 兼容 `/models` 自动发现、Full URL Endpoint Mode
- MCP 服务器：跨应用统一管理、双向同步
- 系统提示词：多预设、跨应用（CLAUDE.md / AGENTS.md / GEMINI.md）
- Skills 管理：GitHub 仓库自动扫描与一键安装、ZIP 安装、批量更新
- 会话管理器：浏览、搜索、恢复全部应用对话历史
- 用量追踪：跨 Provider Token 消耗与费用统计
- 云同步：Dropbox / OneDrive / iCloud / WebDAV
- 跨机迁移：手动导出 / 导入、配置覆盖语义、设备级设置边界
- 跨机排障：旧机器绝对路径污染、provider 快照污染、数据库源数据与 live 配置不一致
- 版本增量：zh-TW 本地化、Codex 第三方 provider 历史统一到 `custom` 桶、实时用量刷新与多项同步稳定性修复（v3.16.0）
- Deep Link：ccswitch:// 协议一键导入配置
- 中转排查：Provider 字段映射、模型 ID 核验、余额 / 配额 / 用量判断顺序
- Codex 特殊案例：切换 Provider 后只有 Codex 终端里的 `node -e` / `npm` 崩溃时，如何从 `shell_environment_policy`、`inherit = "core"` 和 `cc-switch.db` 追根因
- MiMo 专篇：`tp-` / `sk-` 区分、区域 Base URL、Claude Code 模型映射、CC Switch 回写覆盖排查
