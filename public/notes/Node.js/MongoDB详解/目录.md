# MongoDB 详解系列

> 最后按官方资料核对时间：2026-06-06

这一套不是“背概念”的笔记，而是按“小白能看懂、学完能做项目”的目标重写的学习路线。

你会按这个顺序建立完整认知：

1. 先理解 MongoDB 是什么，为什么它和 MySQL 的设计思路不一样
2. 再学 mongosh 与原生 CRUD，知道数据库到底做了什么
3. 接着学 Mongoose，把 Node.js 项目里常见的建模、校验、中间件串起来
4. 然后进入关联、聚合、索引、事务这些项目阶段真正会用到的能力
5. 最后通过一个完整 API 项目，把前面的知识变成“能落地”的代码结构

---

## 这套系列适合谁

适合下面三类同学：

- 完全没学过 MongoDB，希望从零入门
- 已经会写一点 `find()`、`insertOne()`，但对索引、事务、聚合没有体系
- 会用 Mongoose，但不清楚什么时候该嵌入、什么时候该引用、什么时候该上聚合

如果你的目标是“能做 Node.js 项目”，建议直接跟着 1 到 7 顺序学，不要跳着看。

### 当前学习建议

- 如果你是第一次学，概念与语法以 MongoDB 8.x 官方手册为准
- Node.js 新项目建议使用较新的 LTS 运行时，再搭配当前 MongoDB Node.js Driver 与 Mongoose
- Mongoose 很适合业务开发，但它不是“跳过 MongoDB 基础”的理由，前两篇一定要学

## 学完后的能力目标

学完整套后，你至少应该能独立完成下面这些事情：

- 为一个 Node.js 项目设计 MongoDB 数据模型
- 用 mongosh 或官方 Node.js Driver 调试数据库操作
- 用 Mongoose 写出规范的 Model、校验规则、中间件和查询逻辑
- 根据查询场景设计基础索引，而不是“哪里慢了就乱加索引”
- 理解哪些场景适合事务，哪些场景不需要事务
- 独立完成一个带登录、列表、搜索、分页、标签、软删除的后端 API
