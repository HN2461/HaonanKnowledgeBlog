# 网站部署目录

这个子目录专门放“把网站真正发布出去”相关内容。

它适合连续沉淀下面这些主题：

- GitHub Pages 静态部署
- 自定义域名
- DNS 与解析
- HTTPS 与证书
- 云服务器 / VPS
- Nginx 与站点上线
- 自动化发布与持续部署

当前按“先静态部署，再逐步走向完整上线”的顺序整理。

- 项目怎么打包

## 2. 全栈部署入门

如果已经学过 `Node.js`、`Express`、`MongoDB` 和 `Vue`，下一步就可以进入“前后端分离项目上线”路线。

这条路线不要求一开始就精通运维，但至少要能看懂：

- SSH 怎么登录服务器
- Linux 服务器上项目放在哪里
- Vue 打包后的 `dist` 怎么交给 Nginx
- Express 为什么不能只靠 `npm run dev` 常驻运行
- Nginx 为什么要做反向代理
- MongoDB 为什么不能裸露到公网
- 宝塔面板能帮忙做什么，不能替代什么

这组文档现在包含一篇完整实战主线：
