# 第十四篇：Cloud Codex 终端基础操作入门（零基础版）

> 这篇是专门写给主人这种状态的：平时会打开 Cloud Codex，也会在终端里做一些操作，但除了 `cd 路径`，其他命令不太熟。  
> 目标不是把你变成终端高手，而是先让你在真实开发里“够用、顺手、不容易慌”。

[[toc]]

---

## 1. 先别急着背命令，先记住终端里最重要的 4 件事

很多人一看到终端就容易紧张，本质上是因为会觉得：

1. 我不知道自己现在在哪
2. 我不知道这里面有什么
3. 我不知道下一步该输入什么
4. 我怕敲错了把东西弄坏

其实新手前期最重要的，不是一次性背几十条命令，而是先把下面这套顺序养成习惯：

1. 先看自己当前在哪个目录
2. 再看这个目录里有什么
3. 再决定是进去、返回、查看文件，还是运行命令
4. 如果命令跑错或卡住，知道怎么停下来

只要这 4 步顺了，终端就不会再像“纯黑盒”。

---

## 2. 我现在在哪？先学会这个

这是终端里最先要会的一步。

```powershell
pwd
```

或者：

```powershell
Get-Location
```

这两个命令的作用一样，都是查看“我当前所在的目录”。

比如输出可能长这样：

```powershell
Path
----
C:\Users\HN246\Desktop\git项目\个人技术博客网站
```

你可以把它理解成：

- `pwd`：我现在站在哪
- `Get-Location`：完整写法，意思更正式一点

对新手来说，先记 `pwd` 就够用了。

### 什么时候一定要先用它

1. 你刚打开终端时
2. 你不确定自己是不是已经进到项目目录时
3. 你连续 `cd` 了几次之后有点晕时
4. Codex 让你“先在项目根目录执行某条命令”时

一句话记忆：

> 终端里一旦迷路，先敲 `pwd`。

---

## 3. 我想进入某个目录，`cd` 还是核心

这个主人已经最熟了，但我帮你顺一下最常见的 3 种用法。

### 3.1 进入某个目录

```powershell
cd C:\Users\HN246\Desktop\git项目\个人技术博客网站
```

作用：进入指定目录。

### 3.2 返回上一级目录

```powershell
cd ..
```

作用：从当前目录退回上一层。

比如你现在在：

```powershell
C:\Users\HN246\Desktop\git项目\个人技术博客网站\public\notes
```

执行：

```powershell
cd ..
```

就会回到：

```powershell
C:\Users\HN246\Desktop\git项目\个人技术博客网站\public
```

### 3.3 当前目录下继续进入下一级

如果你已经在项目根目录里，还想进 `src`，可以直接：

```powershell
cd src
```

这叫相对路径写法，意思是“从我当前所在位置，进入这个子目录”。

---

## 4. 相对路径和绝对路径，不用学很深，但一定要分清

这是新手很容易绕晕的地方。

### 4.1 绝对路径

绝对路径就是把完整路径从头写到尾：

```powershell
cd C:\Users\HN246\Desktop\git项目\个人技术博客网站
```

特点：

1. 写得最完整
2. 不容易误会
3. 适合你从任何地方直接跳过去

### 4.2 相对路径

相对路径就是“从当前目录出发”去找。

比如你已经在项目根目录：

```powershell
C:\Users\HN246\Desktop\git项目\个人技术博客网站
```

这时进入 `public`：

```powershell
cd public
```

再进入 `notes`：

```powershell
cd notes
```

特点：

1. 更短
2. 更适合你已经在项目附近时继续走
3. 前提是你得知道自己当前在哪

### 4.3 路径里有空格怎么办

如果路径里有空格，要用引号包起来。

比如：

```powershell
cd 'C:\Users\HN246\Desktop\My Project'
```

或者：

```powershell
cd "C:\Users\HN246\Desktop\My Project"
```

单引号和双引号都可以。  
新手先记一个规则就够：

> 路径里只要有空格，就加引号。

## 5. 我想看看当前目录里有什么

这个命令也非常高频。

```powershell
dir
```

或者：

```powershell
ls
```

这两个在 PowerShell 里都能用，作用都是查看当前目录下的文件和文件夹。

你可以把它理解成：

- `dir`：更像 Windows 用户熟悉的写法
- `ls`：很多教程也常见

如果你只想先记一个，我建议记 `dir`。

### 最常见的使用场景

1. 你想确认当前目录里有没有 `src`、`public`、`package.json`
2. 你不确定某个文件到底在不在这里
3. 你刚 `cd` 进一个目录，想先看看里面结构

比如进项目后：

```powershell
dir
```

你可能会看到：

```powershell
Mode   LastWriteTime   Length Name
----   -------------   ------ ----
d----  2026/06/02             public
d----  2026/06/02             src
-a---  2026/06/02       1024  package.json
```

这时候你立刻就知道：

1. 这里是个项目目录
2. 有 `src`
3. 有 `public`
4. 有 `package.json`

## 6. 我想看文件内容，不一定要双击打开

有时候 Codex 会让你先看看某个文件内容，这时不用一定切回图形界面。

### 6.1 快速查看文本内容

```powershell
type README.md
```

作用：直接在终端里显示文件内容。

### 6.2 用 PowerShell 完整写法看内容

```powershell
Get-Content README.md
```

作用也一样，都是查看文件内容。

如果文件内容太长，终端会往下滚，这很正常。

### 什么时候会用到

1. 你想快速看 `README.md`
2. 你想看某个配置文件是不是写对了
3. Codex 让你先确认一个文本文件内容

如果文件很大，新手别在终端里硬看很久。  
终端更适合“快速确认”，不是替代编辑器通读大文件。

## 7. 我想新建文件夹或文件

### 7.1 新建文件夹

```powershell
mkdir demo
```

作用：创建一个叫 `demo` 的文件夹。

比如你当前在桌面某个练习目录里，执行后就会出现一个 `demo` 文件夹。

### 7.2 新建空文件

```powershell
New-Item note.txt -ItemType File
```

作用：创建一个空的 `note.txt` 文件。

这里主人先不用去背 `-ItemType` 的原理，只要知道：

1. `mkdir` 适合新建文件夹
2. `New-Item` 适合更明确地新建文件或目录

如果你只是日常开发里顺手建个目录，记 `mkdir` 就够。

## 8. 我想复制、移动、重命名

这些操作也会偶尔遇到，但先记最基础的理解。

### 8.1 复制文件

```powershell
copy .\note.txt .\note-backup.txt
```

作用：复制一份文件。

### 8.2 移动文件

```powershell
move .\note.txt .\backup\
```

作用：把文件移动到另一个目录。

### 8.3 重命名

```powershell
ren .\note.txt note-new.txt
```

作用：把文件改名。

新手这里先记概念就好：

1. `copy`：复制
2. `move`：移动
3. `ren`：改名

如果你平时很少做这类操作，不用强背参数细节，真用到时再回来查这篇。

## 9. 屏幕太乱、命令卡住、想重跑，怎么办

这部分非常实用，而且新手很需要。

### 9.1 清屏

```powershell
cls
```

作用：把当前终端画面清干净。

注意：

- 它只是把屏幕显示清掉
- 不是删除文件
- 不是清掉你的项目

很多新手看到终端满屏输出会慌，实际上先 `cls` 一下就会舒服很多。

### 9.2 中断当前命令

按：

```text
Ctrl + C
```

作用：停止当前正在运行的命令。

这是终端里非常非常重要的一个操作。

比如这些情况都经常会用到：

1. `npm run dev` 你不想继续跑了
2. 某个命令卡住了
3. 你敲错命令，发现它一直在执行
4. Codex 让你跑了一条命令，但你发现不是你想要的

一句话记忆：

> 终端里“先停下来”，最常用就是 `Ctrl + C`。

### 9.3 重用上一条命令

直接按键盘方向键：

```text
↑
```

作用：把上一条命令调出来。

这非常适合：

1. 你刚才命令只差一点点
2. 你想重跑同一条命令
3. 你不想重新打一遍很长的路径

新手只要先会 `↑`，效率就已经会明显提升。

## 10. 在 Cloud Codex 里最常用的一套最小操作流

如果你平时主要是在 Cloud Codex 里开终端，其实最常用的流程通常就是这一套：

### 第一步：先看自己在哪

```powershell
pwd
```

### 第二步：看当前目录里有什么

```powershell
dir
```

### 第三步：进入项目目录

```powershell
cd '你的项目路径'
```

### 第四步：确认自己进对了地方

```powershell
dir
```

如果你看到了 `src`、`public`、`package.json`、`.git` 这类内容，通常就说明你进对项目了。

### 第五步：再执行项目命令

比如：

```powershell
npm install
npm run dev
git status
```

这里只要先理解它们分别是在做什么：

1. `npm install`：安装项目依赖
2. `npm run dev`：启动开发环境
3. `git status`：看当前仓库有没有改动

你不需要一开始就把它们背出很多变体，先知道“这三条在开发里很常见”就够。

### 第六步：命令不对或不想跑了，就停掉

```text
Ctrl + C
```

这一套已经能覆盖主人平时 70% 以上的基础终端操作。

## 11. 新手先别碰这些高风险操作

这篇我故意不把高风险删除类命令当主线讲，就是因为新手前期最重要的是稳。

比如下面这些，暂时不要把它们当常规操作去乱试：

```powershell
del
Remove-Item
rd
```

原因很简单：

1. 删除操作有时不可逆
2. 你路径一旦看错，可能删错地方
3. 新手前期更需要的是“查看、进入、确认、停止”，不是高风险清理

等你以后终端更熟了，再专门学删除和批量操作会更稳。

## 12. 读到这里，你最该先记住的就这几个

如果主人现在不想记太多，那就先只记下面这些：

```powershell
pwd        # 看我当前在哪
cd 路径     # 进入某个目录
cd ..      # 返回上一级
dir        # 看当前目录里有什么
type 文件名  # 快速看文件内容
mkdir 名称   # 新建文件夹
cls        # 清屏
git status # 看仓库改动状态
```

再额外记住 2 个键盘操作：

```text
Ctrl + C   # 停止当前命令
↑          # 调出上一条命令
```

就够你先把 Cloud Codex 里的终端用顺很多了。
